# Blood Bank Management System

## About the Project
This is a web-based Blood Bank Management System developed using Python, Flask, MySQL and HTML.

## Features
- Donor Registration
- Patient Management
- Blood Request Management
- Blood Stock Management
- Donation Management
- Hospital Management

## Technologies Used
- Python
- Flask
- MySQL
- HTML
- SQL

## Database Tables
1. Donor
2. Patient
3. Blood Request
4. Blood Stock
5. Donation
6. Hospital

## How to Run
1. Install the required Python packages using `pip install -r requirements.txt`.
2. Configure the MySQL database connection.
3. Run `python app.py`.
4. Open `http://127.0.0.1:5000` in your browser.
